# Memory Game

A simple and interactive **Memory Card Game** built with **Vite** and styled using **SCSS**.
The project focuses on fast performance, clean structure, and an enjoyable user experience.

---

## About the Project

This project is a classic memory matching game where players flip cards and try to find matching pairs.
It was created to practice and demonstrate modern frontend development using:

* ⚡ **Vite** for fast development and optimized builds
* 🎨 **SCSS** for modular and maintainable styling
* 🧩 JavaScript game logic and interactive UI handling

The game is lightweight and easy to extend with new features.

---

## Why This Project Is Useful

This repository can be useful for:

* Learning how to structure a frontend project with Vite
* Understanding basic game logic in JavaScript
* Practicing SCSS architecture and component styling
* Exploring DOM manipulation and state handling
* Using the project as a starting point for your own browser games

## Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm

---

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project folder:

```bash
cd memory-game
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Structure

```text
memory/
│
├── public/
│   └── assets/
│       ├── fonts/

├── src/
│   ├── db/
│   │
│   ├── styles/
│   │   ├── abstract/
│   │   ├── base/
│   │   └── components/
│   │
│   └── ts/
│
├── package.json
├── vite.config.js
└── README.md
```

### Folder Overview

- `public/` → Contains static assets like images, fonts, and theme resources
- `src/db/` → Stores game data and card information
- `src/styles/` → SCSS structure with global styles, variables, and component styling
- `src/ts/` → TypeScript files containing the game logic and functionality
